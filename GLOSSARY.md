# CavApps

Tools for the 7th Cavalry Gaming Regiment: the Active Duty Roster, roster statistics and the Uniform Builder.

## Language

### Where the apps run

**Production**:
The stack at apps.7cav.us that members use. It only ever runs a Release.
_Avoid_: live

**Beta**:
The stack at appsbeta.7cav.us where maintainers test one chosen commit before it ships. It holds one commit at a time, and each deploy replaces the last.
_Avoid_: development, dev, staging

**Release**:
A published GitHub release tagged with a bare version number such as 1.5.2.
